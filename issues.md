# issues88

Capture GitHub issues from your phone in seconds. No laptop, no browser tabs, no friction.

## What it does

You notice a bug, an idea, a rough edge — while away from your computer. Open issues88, type one line, tap once. It appears on GitHub immediately. If you are offline, it queues and sends itself when you get signal.

## Features

- One-field capture with optional details and labels
- Offline queue with automatic retry when back online
- Multi-repo — track several projects from one screen
- Labels support (bug, enhancement, idea, custom)
- Sent history with links back to GitHub
- 5 themes cycled by a single button: Ink, Paper, Neon, Clay, Mint
- Built-in guide for first-time users
- Installable PWA — runs full-screen from your home screen

## Setup

1. Create a [personal access token](https://github.com/settings/tokens/new) with the **repo** scope.
2. Open the app → tap the gear icon.
3. Fill in your username, token, and repo names (one per line).
4. Tap **Test** — the dot turns green.
5. Start capturing.

## Privacy

Your token stays only in this browser. All traffic goes directly to `api.github.com`. No third-party server, no analytics, no tracking.

## Tech

Single HTML file. No build step. No backend. Works on any modern browser.
