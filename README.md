## 👋 Bienvenue

CtoA est un outil web qui compile un projet HTML en APK Android. Vous chargez votre code. CtoA génère un projet Android complet, le pousse sur votre dépôt GitHub, et GitHub Actions compile l'APK. Vous récupérez le fichier sans quitter le navigateur. Vous avez besoin d'un compte GitHub gratuit et d'un token personnel.

---

## ✨ Ce que vous trouverez

**Tout dans le navigateur.**  
Aucun logiciel à installer. Aucun SDK Android. Aucun terminal. Vous ouvrez la page et vous travaillez. Tout tient dans un seul fichier HTML.

**Build via GitHub Actions.**  
CtoA pousse votre projet dans un dépôt privé. GitHub compile l'APK en 2 à 4 minutes. Le fichier revient ensuite dans votre navigateur.

**Keystore persistant.**  
Chaque build est signé avec la même clé. Vous installez les mises à jour par-dessus l'ancienne version, sans désinstaller. Gardez le même package ID entre les builds.

**Nettoyage automatique du projet.**  
CtoA supprime les fichiers système, corrige les chemins, ajoute le charset UTF-8, et détecte le fichier d'entrée. Les problèmes courants sont corrigés avant le build.

**Uploads de fichiers pris en charge.**  
`<input type="file">` fonctionne dans l'APK. Sélection simple, sélection multiple, et capture caméra. Les permissions Android sont demandées au premier usage.

---

## 🧭 Comment ça marche

**1. Connectez GitHub.**  
Collez un token personnel. CtoA crée un dépôt privé pour vos builds.

**2. Chargez votre HTML.**  
Déposez un ZIP, un fichier HTML ou un dossier. Maximum 40 Mo.

**3. Lancez le build.**  
CtoA génère le projet Android et le pousse sur GitHub.

**4. Téléchargez l'APK.**  
GitHub Actions compile, publie la release, et CtoA récupère le fichier.

C'est tout. Deux minutes de configuration, trois minutes par build.

---

## 🛠️ Petits coups de main

**Le token est-il en sécurité ?**  
Oui. Il reste dans le localStorage de votre navigateur. Chaque requête va uniquement à `api.github.com`. Aucun serveur tiers, aucun tracking.

**Faut-il un compte GitHub ?**  
Oui. Un compte gratuit suffit. GitHub Actions compile sans frais dans la limite du quota mensuel.

**Puis-je installer les mises à jour sans désinstaller ?**  
Oui. Gardez le même package ID. La clé de signature reste la même entre les builds.

**L'APK est-il signé pour le Play Store ?**  
Non. Il est signé en debug. Il fonctionne pour un usage personnel ou une distribution directe.

## 👋 Welcome

CtoA is a web tool that compiles an HTML project into an Android APK. You upload your code. CtoA generates a complete Android project, pushes it to your GitHub repo, and GitHub Actions builds the APK. You get the file back without leaving the browser. You need a free GitHub account and a personal token.

---

## ✨ What you'll find

**Everything in the browser.**  
No software to install. No Android SDK. No terminal. You open the page and work. Everything fits in one HTML file.

**Build via GitHub Actions.**  
CtoA pushes your project to a private repo. GitHub compiles the APK in 2 to 4 minutes. The file comes back to your browser.

**Persistent keystore.**  
Every build is signed with the same key. You install updates over the old version, no uninstall needed. Keep the same package ID between builds.

**Automatic project cleanup.**  
CtoA removes system files, fixes paths, adds the UTF-8 charset, and detects the entry file. Common issues are fixed before the build.

**File uploads supported.**  
`<input type="file">` works inside the APK. Single selection, multiple selection, and camera capture. Android permissions are requested on first use.

---

## 🧭 How it works

**1. Connect GitHub.**  
Paste a personal token. CtoA creates a private repo for your builds.

**2. Upload your HTML.**  
Drop a ZIP, an HTML file, or a folder. Max 40 MB.

**3. Start the build.**  
CtoA generates the Android project and pushes it to GitHub.

**4. Download the APK.**  
GitHub Actions compiles, publishes the release, and CtoA fetches the file.

That's it. Two minutes of setup, three minutes per build.

---

## 🛠️ A little help

**Is the token safe?**  
Yes. It stays in your browser's localStorage. Every request goes only to `api.github.com`. No third-party servers, no tracking.

**Do I need a GitHub account?**  
Yes. A free account is enough. GitHub Actions builds for free within the monthly quota.

**Can I install updates without uninstalling?**  
Yes. Keep the same package ID. The signing key stays the same between builds.

**Is the APK signed for the Play Store?**  
No. It is debug-signed. It works for personal use or direct distribution.
