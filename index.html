About MC88 STUDIO

What is this

MC88 STUDIO is a small collection of utilities built around the same idea: give simple, honest tools that talk straight to GitHub from your own browser. No accounts, no servers, no hidden costs. Each tool is one HTML file you can host anywhere, or just open locally.

The three tools

  • CtoA88 — turn an HTML project into an Android APK, built in the cloud.
  • push88 — a bridge between your phone and a GitHub repository for file transfer.
  • issues88 — capture GitHub issues in one tap, offline-friendly, from anywhere.

How to use

Pick a tool from the three cards. Each one has its own first-time setup with a guide built in — usually just pasting a GitHub token you create once. After that, they open and work.

Privacy

Your tokens and files stay only on your device and go directly to GitHub. Nothing is logged, nothing is proxied, nothing is tracked. If you lose your device, revoke the token from GitHub settings — that is all you need to do.

Install as app

Open any tool in Chrome or Edge, then use Install app from the browser menu. It will open full-screen from your home screen like a native app.
