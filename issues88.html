How issues88 helps you

issues88 is a notebook for GitHub issues. You notice something on your project while away from your computer, you write it here in three seconds, and it lands on GitHub automatically. No laptop, no browser tabs, no friction.

First time setup

  1. 1
    Create a personal access token on GitHub with the repo scope.
  2. 2
    Open Settings (gear icon) and paste your username, token and repo names.
  3. 3
    Tap Test. You should see a green confirmation.

Daily use

  1. 1
    Type a short title of what you noticed.
  2. 2
    Optionally open add details and write more context.
  3. 3
    Tap any labels you want the issue tagged with.
  4. 4
    Choose the repo from the dropdown.
  5. 5
    Tap Capture issue. It goes to GitHub immediately.

What it can do

Instant capture

One field, one tap. From pocket to GitHub in seconds.

Offline queue

Write on the subway. It sends itself when you have signal again.

Multi-repo

Track issues across several projects from one screen.

Labels

Tag as bug, idea, urgent — before you forget why it mattered.

Retry

Any failed issue stays in the queue. One tap retries it.

Installable

Add to home screen. Runs like a native app, no store needed.

Good to know

  1. ·
    Your token stays only on this device. Nothing is sent to any server other than GitHub itself.
  2. ·
    Press Ctrl + Enter to capture without leaving the title field.
  3. ·
    Tap the theme icon at the top to switch between Ink, Paper, Neon, Clay and Mint.
  4. ·
    The green dot on the gear means you are connected. Red means the token is missing or wrong.
