How to use CtoA

code to app · by MC88

CtoA turns an HTML project into a real Android APK. Everything runs in your browser. You set up GitHub once, then every build is upload, click, download.

One-time setup (2 minutes)

  1. Create an account at github.com/signup if you do not have one.
  2. Go to github.com/settings/tokens/new.
  3. Name it ctoa. Expiration: No expiration.
  4. Check only these scopes: repo and workflow.
  5. Click Generate token. Copy it (starts with ghp_).
  6. Paste the token in CtoA. Done forever.

Every build

  1. Upload your project (.zip · .html · folder).
  2. Review the sanitizer report. It fixes common issues automatically.
  3. Set the app name, package ID, icon.
  4. Click Build APK now.
  5. Wait 2-4 minutes. The APK downloads automatically.

File uploads inside your app

  1. Any <input type="file"> in your HTML works inside the built APK.
  2. Single and multiple file selection both supported.
  3. Camera capture via accept="image/*" capture works too.
  4. Runtime storage permissions are requested automatically on first use.
  5. Downloads triggered by your app land in the Downloads folder.

How it works behind the scenes

  1. Your HTML is sanitized in the browser (junk removed, paths fixed).
  2. CtoA generates a complete Android Studio project.
  3. The project is pushed to your private GitHub repo via the GitHub API.
  4. GitHub Actions detects the push and starts building.
  5. Gradle compiles the APK in the cloud (2-4 minutes).
  6. The workflow publishes the APK as a GitHub Release.
  7. CtoA downloads it and hands it to you.

Updates without uninstalling

  1. The workflow uses a persistent debug keystore.
  2. Every new build is signed with the same key.
  3. You can install updates over the old version. No need to uninstall.
  4. Keep the same packageId between builds.

Privacy and security

  1. Your code never touches our servers. There are no servers.
  2. The token is stored in your browser's localStorage.
  3. Every request goes only to api.github.com.
  4. You can revoke the token anytime from GitHub settings.
  5. No analytics. No tracking. No ads. No third parties.

Free tier limits

  1. Private repos: 2,000 build-minutes per month, about 660 builds.
  2. Public repos: unlimited build-minutes.
  3. Each build takes 2-4 minutes.
  4. Old releases are cleaned automatically (10 latest kept).

What is inside the APK

  1. A native Android WebView activity that loads your HTML.
  2. Everything runs offline. Your HTML, CSS, JS, images are bundled.
  3. Auto-rotate, back button, external links open in browser.
  4. Full file upload support: single, multiple, camera.
  5. Works on Android 7.0 and above (minSdk 24).
  6. Debug-signed. Perfect for personal use. Not for Play Store.
